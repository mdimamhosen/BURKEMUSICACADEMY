# Squarespace rebuild checklist

Use this after the homepage concept is approved and you have a Squarespace trial or contributor access to BMA’s live site.

1. Keep the existing Squarespace template and BMA brand. Rebuild the homepage sections in Fluid Engine in the order shown in the mock.
2. Keep the existing logo and colors. Use custom CSS only for type scale, buttons, and spacing where Fluid Engine settings do not cover them.
3. Build the homepage in this order: hero, quick facts, disciplines, BMA approach and seven pillars, tracks, consultation steps, faculty, performance opportunities, student stories, testimonials, albums, scholarship information, FAQs, consultation booking, and footer.
4. Link every consultation CTA to `/bma-application`. Link the Enrollment Guide separately.
5. Use the approved BMA photos and album art. Compress uploaded images as needed, add descriptive alt text, and confirm each image still displays well on mobile.
6. Set the homepage SEO title and description, then check social sharing metadata.
7. Check the page at iPhone width, tablet width, and desktop width. Confirm the navigation, buttons, page anchors, address, phone, email, and hours.
8. Keep Tuesday–Friday hours at 10am–8pm to match the current homepage footer.

The Musical Theater card currently leads to the consultation section because no matching page appeared in the live Programs list when this concept was prepared. Replace that anchor if BMA approves or publishes a dedicated page. Faculty credentials, student examples, and scholarship language in the concept are based on the public BMA pages; confirm they are still current during the Squarespace rebuild.
